# Project Manager

## Visão geral
Este repositório organiza o projeto PM de forma simples e profissional, separando claramente os arquivos de código-fonte, cabeçalhos, artefatos de compilação e binários gerados.

## Estrutura do projeto
- [Makefile](Makefile): arquivo de automação para compilação e execução.
- [include/](include): diretório com os cabeçalhos do projeto.
- [src/](src): diretório com os arquivos-fonte em C.
- [build/](build): diretório para arquivos intermediários da compilação.
- [bin/](bin): diretório para os executáveis gerados.
- [.gitignore](.gitignore): regras de exclusão para o Git.

## Organização adotada
- Os arquivos de implementação ficam em [src/](src).
- As interfaces e definições compartilhadas ficam em [include/](include).
- Os artefatos de compilação são mantidos em [build/](build) e [bin/](bin).
- A organização foi preservada sem adicionar ou remover arquivos, apenas deixando a estrutura mais clara e profissional.

## Observações
A documentação foi ajustada para refletir melhor a estrutura atual do projeto e facilitar a leitura e manutenção.
